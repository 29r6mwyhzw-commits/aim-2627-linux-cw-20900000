# 公开测试与评分数据

本目录由教师维护，学生只读。GitHub CI 和本地自测使用同一套检查，没有其他 grader 或隐藏测试。

| 文件 | 用途 |
|---|---|
| `coursework.py` | 全部场景的输入生成、训练环境准备、断言和评分权重 |
| `test_feedback.py` | 终端诊断输出的回归检查，不给学生作业计分 |
| `test_preflight.py` | 启动前检查程序的自检，不给学生作业计分 |
| `skeleton-sha256.json` | 九个原始答题文件的校验值，用于识别尚未开始的模板 |
| `__init__.py` | Python 测试模块入口 |

`skeleton-sha256.json` 不存题目输入、答案或学生成绩。完全未修改的原始骨架可以初始化 CI，仍为 0 分、未开始；答题文件修改后继续返回 77 也不会因此通过考核。

每个评分小项需要通过该题全部场景才获得该小项分数。实际测试入口是 `tools/run_tests.py`；通过 `bash tools/test.sh` 调用，不需要学生直接运行或修改测试源码。
